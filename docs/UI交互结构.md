# UI 交互结构

## 导航原则

- 顶部只切换三个目的地：游戏库、运行时、设置；不叠加第二层页面侧边栏。
- 分类、搜索、列表／卡片切换同属游戏库工具栏，筛选无结果时也不能消失。
- 列表模式：左侧快速切游戏，右侧看详情。卡片模式：整库浏览，进入详情后可「返回游戏库」。
- 游戏详情的封面、身份、启动／停止、编辑、更多操作保持可见；下方只滚动当前标签的内容。
- 概览放作品信息；存档放导入导出和存档状态；运行信息放路径、进程和引擎参数，并可跳转运行时管理。
- 编辑使用模态表单，避免切页／切游戏导致草稿消失。「完成」遇到未保存修改先确认；有修改时禁止手势关闭。分类仍为即时保存，提示中明确说明。
- 运行时页区分可安装与仅识别；已装运行时的低频操作收进更多菜单。卸载需确认，有游戏运行时禁用卸载。
- 存档备份是始终可用的手动操作，不提供无实际作用的「同步」开关；旧设置字段保留兼容。
- 设置按组查看；未实现的选项默认收起、不可编辑，不再给人「改了应该生效」的错觉。

## 快捷键

- `⌘O`：添加游戏。
- `⌘F`：聚焦游戏搜索。
- `Return`：详情页启动／停止游戏（输入和弹窗中的按键由对应控件处理）。
- `Esc`：卡片详情返回游戏库。
- `⌘S`：保存编辑表单。

## 验收

在 Mac 执行 `swift build`、`swift test`、`.build/debug/Tsumigeya --snapshot /tmp/tsmg-ui`。

新增快照覆盖卡片整库、存档、运行信息、900×600 最小窗口、浅色模式，以及全部设置分组。为验证显示方式创建临时 JSON 副本，不改写用户的视图设置。

仍需在真实窗口手工确认：

1. 连续切游戏、切详情标签，运行按钮与信息对应正确，长标题不遮挡操作。
2. 列表和卡片切换、卡片进入与返回、键盘搜索、搜索无结果后清除筛选。
3. 编辑后尝试关闭；取消放弃应保留草稿，确认放弃不写入本地信息；保存后重开值一致。
4. 缺失／空／有存档三种状态，以及运行中禁用导入导出；不能只看按钮就判归档逻辑通过。
5. 运行时安装进度、失败与取消；打开卸载确认后取消，不能误删运行时。
6. 设置切组与重启后的偏好持久化；未实现的设置不能操作。
7. 真窗口中的封面加载和比例。离屏 `AsyncImage` 不下载是快照工具限制，不能把占位图当作封面验收通过。

这轮不修改数据 schema、引擎识别、游戏启动或存档打包逻辑。
