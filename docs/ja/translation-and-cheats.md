# 翻訳とチート

[English](../en/translation-and-cheats.md) · [简体中文](../翻译与作弊.md) · **日本語**

> Tsumigeya の画面は簡体字中国語・英語・日本語に対応しており（設定 → 言語）、既定ではシステム言語に従います。本書では画面内の項目名を原文である簡体字中国語で「」に引用し、初出時に日本語名を添えています。英語版の画面では同じ項目が英語で表示されます。

ゲーム詳細の翻訳（「翻译」）とアシスト（「辅助」）という 2 つの独立したタブで使います。**起動・翻訳・チートは 3 つの異なる機能**です。エンジン管理（「引擎管理」）タブがそれぞれの対応範囲を示します。あるエンジンを起動できても、そのテキストやゲーム状態に接続済みとは限りません。

## 内蔵アシストモジュール

既存のアシストはエンジン別に 4 種類の内蔵モジュールへ分かれています。MV/MZ、XP/VX/VX Ace、Ren'Py、Tyrano です。モジュールはアプリに同梱され、追加のダウンロードは不要です。外部プラグインの読み込みやプラグインストアではありません。

- 各モジュールは自身のゲーム認識、テキスト抽出、アシストスクリプト、操作説明を担当します。AI インターフェース、訳文ディレクトリ、バックアップ検証、タスク管理は共通です。
- 翻訳とチートはそれぞれ対応範囲を宣言し、個別に有効化します。実行時の機能ページとゲーム詳細は同じモジュール宣言を読むため、起動できることを翻訳やチートができると書き誤ることはありません。
- モジュールの整理にあたっても、既存のゲーム識別情報、設定形式、人手による訳文、アシストのインストール記録は保持され、インターフェースの再入力や訳文ディレクトリの作り直しは不要です。今後モジュールを追加したり機能を補ったりしても、他のエンジンの対応範囲が自動的に広がるわけではありません。

## エンジン対応範囲

| ゲームの種類 | 翻訳の接続 | チートの入口と範囲 |
|---|---|---|
| RPG Maker MV / MZ | データベース／イベントテキストの抽出、表示時の置換と未ヒットの捕捉 | ゲーム内の「游戏辅助」（ゲームアシスト）／`⇧F8`。所持金、アイテム、アクター、変数／スイッチ、ロック、数値の絞り込み、速度／壁抜け／エンカウント、マップ／イベント／戦闘の操作 |
| RPG Maker XP / VX / VX Ace（mkxp-z） | 既存の互換プリロードを保ち、独立したアシストを追加。初回のゲーム起動後にデータベースとマップイベントを抽出し、表示時に置換 | ランチャーの詳細ページ。所持金、アイテム／武器／防具、パーティのアクターの HP／MP／レベル、数値変数とスイッチ、ロックと数値の絞り込み |
| Ren'Py | 可視ソースからセリフとテキスト選択肢を読み取る。表示時に置換し、動的コンテンツを捕捉 | ランチャーの詳細ページ。ゲームが公開している単純な数値・真偽値・短いテキストの変数、ロックと数値の絞り込み。複雑なオブジェクトやエンジン制御フィールドは編集しない |
| TyranoScript / TyranoBuilder | `.ks` のセリフ抽出、テキストとテキスト選択肢タグの表示時置換、動的コンテンツの捕捉 | ゲーム内の「游戏辅助」（ゲームアシスト）／`⇧F8`。`f` ゲーム変数と `sf` システム変数の単純な値、ロックと数値の絞り込み |
| その他のエンジン | 未対応 | 未対応。起動に対応しているからといってチート対応として表示されることはありません |

**検証範囲**：MV/MZ と VX Ace は実ゲームのコピーで検証済みです。XP は公式の無料サンプル《KNight-Blade》、VX は無料のオリジナル版《魔女之家》1.09a を使用し、XP のメニュー／対話、VX のメニュー表示、および両者の所持金／アイテム／アクター／変数とスイッチの編集、ロック、実行時の抽出を確認しました。Ren'Py は 8.5.2 SDK の自作サンプルを使用しています。Tyrano は公式の Tyrano V5 自作サンプルに加え、無料作品《放課後ネットミームカルタ》の元のスクリプトで対話／選択肢の訳文と単純な変数の編集を検証しましたが、その Electron ダウンロードパッケージは隔離したコピーを NW.js ホストに調整したうえでしかテストしておらず、**Electron の元パッケージがそのまま起動できることを意味しません**。上記の訳文表示の検証は既製の辞書を使っており、ユーザーの有料 AI サービスを呼び出したことを意味しません。実測はいずれも該当サンプルに対するものであり、全作品の互換性を約束するものではありません。

**既知の制限**：《Star Stealing Prince》3.2 は現在の mkxp-z／Ruby で古いスクリプトの構文エラーが発生し、アシストを外しても再現するため、まだゲームに正常に入れません。Ren'Py 7／Python 2、独自に改変されたエンジン、特殊なプラグインについては一般的な互換性を保証しません。Tyrano の Electron／ASAR パッケージには自動変換の対応がなく、現在の接続は NW.js でそのまま開けるディレクトリを対象としています。

## 翻訳

- 原文 → 訳文の JSON オブジェクトに対応し、この構造の MTool 訳文も含みます。ネストした形式、コメント、制御文字の不一致は拒否し、形式を推測することはありません。
- 「提取游戏文本」（ゲームテキストを抽出）はエンジンごとに抽出方法を選びます。MV/MZ はデータベースとイベントを読み取ります。RGSS は先にアシストを適用し、ランチャー経由で一度ゲームに入ってから戻って抽出します。Ren'Py のソース解析は Python、画面、複数行のコードブロックを意図的に飛ばします。アーカイブや複雑な構文は実行時の捕捉を使います。Tyrano はスクリプト／HTML タグのブロックを飛ばします。テキスト選択肢は実行時に捕捉できます。
- 自動翻訳にはチャット補完リクエストに互換な**完全なインターフェースアドレス**、モデル、対象言語の入力が必要です。任意の AI サービスを使えます。リモートのインターフェースは HTTPS のみ、ローカルのインターフェースは HTTP も使えます。キーは macOS のキーチェーンに保存され、ゲームディレクトリには書き込まれません。ゲームのテキストは入力したサービスへ送信され、費用が発生する場合があります。
- 一時停止と再開、失敗した項目だけの再試行、検索、手作業での修正ができます。1 件ずつ保存され、成功した訳文は再要求されず、再抽出しても既存の修正は上書きされません。ゲームの制御文字とプレースホルダーは保持が必須で、Ren'Py の補間やテキストタグも含みます。
- 「跟随游戏补译」（ゲームに追従して追訳）は、ゲームの表示時に捕捉した未ヒットのテキストを処理し、ローカルキャッシュを更新します。ランチャーを開いたままにしておく必要があります。一時停止や終了の後も、ゲームは既存の訳文または原文を表示し続けます。既存の画面は通常、次回の再描画時に更新されます。
- RGSS の 1 文字ずつのセリフは、文字に分解する前に翻訳します。中国語、日本語とその約物の計測・描画には一貫したフォントを使います。翻訳を有効にすると、macOS 標準の Arial Unicode フォントをランチャーのデータディレクトリの `assist-fonts/` にキャッシュし、追加の素材パスとして読み込みます。ゲームディレクトリには書き込まず、アプリに同梱して配布することもありません。翻訳をオフにすると、このパスは追加されなくなります。キャッシュが壊れている場合や安全でないリンクがある場合は起動を停止し、疑わしいファイルを上書きしません。
- Tyrano は実行時に `iscript`／HTML ブロック内のテキストを翻訳も捕捉もしません。プログラムコードをセリフと誤認しないためです。
- 画像内の文字、手描きの字形、動的な結合、一部のプラグインのテキストは完全な網羅を保証しません。未ヒットのときは原文を残し、翻訳の失敗でゲームを止めることはありません。

訳文ディレクトリはデータルートの `translations/<ゲーム識別子>.json` にあり、インターフェース設定は `translation-service.json` です。識別子は正規化したディレクトリとエンジン固有の特徴データの両方で照合します。MV/MZ は入口とシステムデータ、RGSS はスクリプトデータまたは対応バージョンのアーカイブ、Ren'Py はシナリオ／アーカイブ（キャッシュ、セーブデータ、アシストの入口を除く）、Tyrano はエンジンとシーンの特徴を使います。ゲームを移動したり特徴ファイルが変わったりした後、ゲームライブラリの番号だけで古いキャッシュを適用することはありません。

## チート

**先にセーブデータをバックアップしてください。** 変更は物語を変え、セーブデータに書き込まれることがあります。アシストをオフにしたり削除したりしても、すでに変更した所持金、アイテム、アクターの能力値、物語の状態は元に戻りません。`sf` はセーブデータをまたぐシステム変数なので、変更の影響もセーブデータをまたぐ場合があります。

- MV/MZ、Tyrano：ゲーム右上の「游戏辅助」（ゲームアシスト）をクリックするか、`⇧F8` を押します。パネルは入力がゲームへ伝わるのを遮り、変更には確認が必要です。
- RGSS、Ren'Py：アシストを適用したうえでランチャーからゲームに入り、詳細ページの「作弊工具」（チートツール）へ戻ります。通常の入力欄では数値やテキスト、トグルでは真偽値を編集します。確定するとゲームへ送信され、ゲームからの応答が表示されます。接続が期限切れの場合やタイトル画面のままの場合は編集できません。
- 数値の検索は既知／未知の初期値に対応し、増加・減少・変化・未変化の逐次絞り込みができます。プロセスメモリ全体を走査するのではなく、各検索時のスナップショットを比較します。一覧は最大 100 件まで表示され、名前、キー、数値で検索できます。
- 変更してロックすると目標値を定期的に維持します。通常の変更はその項目の以前のロックを解除します。項目ごとの解除も、すべてのロックの解除もできます。ニューゲームやロードでは以前のロックと検索が解除され、前回のロックを新しい状態に押し付けることはありません。
- RGSS は公開されている状態だけを操作します。アイテム、所持金、アクターのレベルなどはエンジンの範囲に従い、HP／MP などは現在の上限を超えません。Ren'Py は任意の Python を実行せず、Tyrano は任意の JavaScript を実行しません。接続するのは単純な値と制限された経路だけです。
- MV/MZ のマップ移動、イベント実行、戦闘操作は現在のシーンとビジー状態を確認し、追加の確認を求めます。カスタムプラグインは引き続き動作に影響する可能性があります。他のエンジンには、未実装の MV/MZ 専用ツールは表示されません。

## 適用と削除

翻訳とチートは個別に有効化します。ゲームを終了してから「应用到游戏」（ゲームに適用）をクリックします。元のデータベースやシナリオを置き換えることはありません。訳文を修正した後は再適用でき、ゲームに追従しての追訳は実行時辞書を自動で更新します。

- **MV/MZ、Tyrano**：入口ページの末尾に独立したスクリプトを読み込みます。アシストのファイルと元の入口のバックアップは、入口の隣の `.tsumigeya-assist/` に置きます。削除時は検証してページをバイト単位で復元します。
- **RGSS**：ゲームディレクトリには `.tsumigeya-assist/` だけを追加します。起動計画は既存のプリロードの後にアシストを追加し、`Scripts`／ゲームのアーカイブは変更しません。必ずこのランチャーから起動する必要があります。削除後は次の起動でアシストを追加しません。
- **Ren'Py**：`game/` に独立した `zz_tsumigeya_assist.rpy` と `.tsumigeya-assist/` を追加し、元のシナリオは残します。アシストの状態は独立したモジュールに留まり、初期化用のローカル変数はゲームのセーブデータに加わりません。削除時は本ツールの入口とコンパイル済みファイルも整理します。

適用前にはゲームの識別子、所有するスクリプト、元の入口を照合します。外部からの改変、同名ファイル、未知のファイル、安全でないシンボリックリンクがある場合は上書き／整理を停止します。実行中はインストール、更新、復元ができません。削除してもランチャーの訳文ディレクトリは残ります。ネイティブの状態コマンドには現在のゲーム識別子、実行セッション、短い有効期限が含まれ、期限切れのコマンドやロード前のコマンドが新しいセッションに書き込まれることはありません。

ゲームの動作はランチャーの存続に依存しません。ただしランチャーを閉じると、RGSS／Ren'Py の状態編集画面と、全エンジンのゲームに追従しての追訳は停止し、ゲームは読み込み済みのアシストと既存の辞書を保持します。

## オフライン補助

ゲームのランタイムに注入せず、ゲーム自身のファイルを直接読み書きします。書き込み前に同じディレクトリへ `.tsumigeya-bak` を作成し、既存のバックアップは上書きしません。

- **NScripter**：`0.txt` / `00.txt` / `nscript.dat`（末尾は 1 バイトごとに XOR 0x84）を読み、引用符で始まる行の本文だけを置換します。コマンド行、コメント、`*label` は変更せず、各行の改行コードも維持します。書き戻しは元の文字コードを使い、中国語を格納できない場合は UTF-8 に切り替えて報告します。その場合ゲームの `--enc` 引数も同じ文字コードに変更する必要があります。
- **RPG Maker MZ**：`save/*.rmmzsave` は `LZString.compressToBase64(JsonEx.stringify(...))` です。`JsonEx` の 8 文字のハッシュ接頭辞はそのまま残し、JSON 内のスカラー値だけを変更します。型が一致しない置換は拒否します。
- **RPG Maker XP / VX / VX Ace**：`.rvdata2` / `.rxdata` は Ruby Marshal です。再シリアライズすると共有参照が複製に展開されるため行わず、各スカラーのバイト範囲だけをその場で置換します。`@n` 参照を含む他のバイトは変更しません。変更できるのは数値、真偽値、文字列のみです。
- **RPG Maker 2000 / 2003**：`RPG_RT.ldb` は LCF コンテナです。アクター、スキル、アイテム、敵、地形、状態、コモンイベント、スイッチ、変数の名前と説明を抽出できます。**読み取り専用**で、書き戻しには chunk ツリー全体の再構築と各長さの再計算が必要です。

検証範囲：NScripter は平文・暗号化・3 種類の文字コードを確認済み。MZ と RGSS は生成したサンプルのみで検証しており、**実作のセーブデータは未確認**です。EasyRPG の `.lsd` セーブと吉里吉里の `.xp3` は未対応です。

## CLI 検証

```bash
swift run tsumigeya-cli assist inspect <game-dir>
swift run tsumigeya-cli assist extract <game-dir>
swift run tsumigeya-cli assist install <game-dir> --translation --cheats
swift run tsumigeya-cli assist state <RGSS-or-RenPy-dir>
swift run tsumigeya-cli assist command <RGSS-or-RenPy-dir> set <var-key> <json-value>
swift run tsumigeya-cli assist restore <game-dir>
swift run tsumigeya-cli offline script-inspect <game-dir>
swift run tsumigeya-cli offline script-apply <game-dir> <dictionary.json>
swift run tsumigeya-cli offline save-inspect <save-path>
swift run tsumigeya-cli offline save-set <save-path> party._gold 4200
swift run tsumigeya-cli offline ldb-inspect <RPG_RT.ldb>
node --test Tests/TsumigeyaTests/Assist/runtime.test.cjs
python3 Tests/TsumigeyaTests/Assist/renpy_runtime_test.py
ruby Tests/TsumigeyaTests/Assist/rgss_runtime_test.rb
```

`assist install` は初回に空の辞書を使い、繰り返し実行すると既存の訳文を保持します。実際の取り込み、翻訳、訳文の適用は画面から行ってください。`assist command` が返すのは送信番号であり、変更が成功したことを意味しません。`state` で `ack` と `error` を確認してください。検証は独立したゲームのコピーとデータディレクトリで行い、私用のセーブデータで破壊的な操作を試さないでください。
