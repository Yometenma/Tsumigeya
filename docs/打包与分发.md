# 打包与分发

## 生成安装包

在 macOS / Apple Silicon 上，使用 Swift 6.2+ 和匹配的 macOS SDK：

```bash
cd mac-native
swift build
swift test
TSUMIGEYA_VERSION=2.2.0 bash scripts/package-macos.sh
```

发版时显式设置目标版本。脚本构建 release、组装 app、复制 `assets/icon.icns`、ad-hoc 签名并生成 DMG；产物在 `mac-native/dist/`，不提交。当前不提供 `--universal` 参数，打包架构跟随构建机器。

## 签名限制

当前没有 Apple Developer 账号或分发证书，**不做公证**。ad-hoc 签名不等于 Developer ID 签名，也不保证下载后不被 Gatekeeper 拦截。

若系统阻止打开，用户应先确认来源可信，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/Tsumigeya.app
```

Release 说明必须包含最低系统版本、架构、未公证说明及上述处理方式。不要承诺“必定可直接打开”或“必定被拦截”。

## 发布前检查

1. 检查版本、图标、`Info.plist` 和可执行文件；`codesign --verify --deep --strict` 验证签名完整性。
2. 从 DMG 安装到应用目录，通过 `open /Applications/Tsumigeya.app` 启动，确认窗口和核心操作；`spctl` 的策略结果、进程存在或直接执行包内二进制都不能替代用户启动路径。
3. 用真实游戏验证启动、关闭启动器后游戏仍运行，以及存档导入导出。
4. 在带下载隔离标记的安装包上检查首次打开流程；单机实验不代表所有系统版本的行为。

旧 Electron / Windows 构建流程已移除；原生版尚未配置自动构建与发布，当前走 Mac 本机打包。

## 图标维护

源图为 `assets/icon-source.jpg`，打包图标为 `assets/icon.icns`。安装 Pillow、NumPy 后，在仓库根运行 `python scripts/make-icon.py`；预览、母版及调色板输出到 `.dev-scratch/icons/`，不提交。
