
## 翻译与作弊

游戏详情的「翻译与作弊」页支持已确认的 RPG Maker MV/MZ 游戏。它不是跨引擎通用内存修改器；普通 NW.js 游戏和其他引擎不会被误标为可用。

### 翻译

- 可导入原文到译文的平面 JSON 字典，包括采用此结构的 MTool 译文；嵌套格式、注释和控制符不匹配会被拒绝，不自动猜测格式。
- 「提取游戏文本」读取对话、选项、说话人、角色和物品等数据库文字、系统用语，不执行游戏脚本，也不遍历翻译脚本字符串或资源路径。
- 自动翻译需要用户填写兼容聊天补全请求的**完整接口地址**、模型和目标语言。远程接口只允许 HTTPS，本机接口允许 HTTP。密钥保存在 macOS 钥匙串，不写进游戏目录。游戏文字会发送到所填服务，可能产生费用。
- 可暂停继续、仅重试失败项、搜索和手动修订。逐条保存；成功译文不重复请求，重新提取不会覆盖已有修订。游戏控制符与占位符必须保留。
- 「跟随游戏补译」处理游戏显示时捕获的未命中文字，更新本地缓存；需要启动器保持开启。暂停或退出后，游戏继续显示已有译文或原文。现有画面中的文字通常在下次重绘时更新。
- 游戏本身已有的图片文字、自绘字形、动态拼接及部分插件文字不保证完整覆盖。对未命中内容保留原文，不以翻译失败阻止游戏。

译文目录位于数据根目录的 `translations/<游戏身份>.json`，接口配置为 `translation-service.json`。身份包含规范目录、入口、引擎版本种类和系统数据库校验值，避免相同编号或替换游戏后混用缓存。

### 作弊

启用后，在游戏右上角点击「游戏辅助」，或按 `⇧F8`。进入地图或读档后可以使用：

- 金钱、物品／武器／防具数量、角色等级和属性、恢复与战斗控制。
- 变量和开关的编号／名称搜索、修改、数值锁定与解除；复杂对象只读。
- 已知或未知初始数值查找，以及按增加、减少、变化、未变化逐次筛选。范围是游戏变量、金钱和当前队伍的生命／魔力／特技点／等级，不是整个进程的任意内存。
- 地图逻辑加速、移动速度、穿墙和随机遇敌控制。
- 地图查找、坐标传送、地图事件查看和执行、公共事件查看和执行。战斗、事件执行等不安全时机拒绝相关操作。

**请先备份存档。** 作弊可能写入存档；关闭或卸载辅助功能不会撤销已有金币、物品、角色属性或剧情变化。新游戏和读档会解除本次锁定、搜索及临时辅助。地图传送、事件执行和变量／开关修改有额外确认，但仍可能破坏剧情。

### 安装与恢复

两项功能独立启用。退出游戏后点击「应用到游戏」；脚本在原页面末尾加载，不整份替换 `main.js`，不改原始数据库。辅助文件和原始页面备份放在入口页面旁的 `.tsumigeya-assist/`。修改入口后会记录校验值；入口、备份或游戏身份变化时拒绝覆盖。

「恢复原始入口」会校验并恢复原始页面、移除辅助文件，保留启动器中的译文。存在自添文件时停止清理，避免误删。应用会检查目标游戏进程，运行时不能安装、更新或恢复。加载后的游戏与作弊不依赖启动器存活。

CLI 验收入口：

```bash
swift run tsumigeya-cli assist inspect <游戏目录>
swift run tsumigeya-cli assist extract <游戏目录>
swift run tsumigeya-cli assist install <游戏目录> --translation --cheats
swift run tsumigeya-cli assist restore <游戏目录>
node --test Tests/TsumigeyaTests/Assist/runtime.test.cjs
```

`assist install` 用于接入验收，首次安装使用空字典，重复安装保留已有译文；实际导入、翻译和应用译文请使用界面。请在独立游戏副本和数据目录验收，不用私人存档验证破坏性操作。
