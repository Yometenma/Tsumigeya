# 翻译与作弊

在游戏详情的「翻译」与「辅助」两个独立页中使用。**启动、翻译、作弊是三种不同能力**：「引擎管理」页分别列出支持范围；能启动某个引擎，不等于已经接入其文字和游戏状态。

## 内置辅助模块

现有辅助按引擎分为四类内置模块：MV/MZ、XP/VX/VX Ace、Ren’Py 和 Tyrano。模块随应用提供，不需要额外下载；这不是外部插件加载或插件商店。

- 各模块负责自己的游戏识别、文本提取、辅助脚本及操作说明；AI 接口、译文目录、备份校验和任务管理共用。
- 翻译与作弊分别声明支持范围、独立启用；运行时能力页和游戏详情读取相同的模块声明，不把能启动误写成能翻译或作弊。
- 模块整理保留现有游戏身份、配置格式、人工译文和辅助安装记录，不需要重新填写接口或重新建立译文目录。后续新增模块或补充能力不等于其他引擎的兼容范围自动扩大。

## 引擎范围

| 游戏类型 | 翻译接入 | 作弊入口与范围 |
|---|---|---|
| RPG Maker MV / MZ | 数据库／事件文本提取，显示时替换与未命中捕获 | 游戏内「游戏辅助」／`⇧F8`；金钱、物品、角色、变量／开关、锁定、数值筛选、速度／穿墙／遇敌、地图／事件与战斗控制 |
| RPG Maker XP / VX / VX Ace（mkxp-z） | 保留原兼容预加载，增加独立辅助；首次进入游戏后提取数据库与地图事件，显示时替换 | 启动器详情页；金钱、物品／武器／防具、队伍角色生命／魔力／等级、数值变量与开关、锁定与数值筛选 |
| Ren’Py | 读取可见源码中的台词和文字选项；显示时替换、捕获动态内容 | 启动器详情页；游戏公开的简单数字、布尔值、短文字变量，锁定与数值筛选；不编辑复杂对象及引擎控制字段 |
| TyranoScript / TyranoBuilder | `.ks` 台词提取，文字与文字选项标签显示替换、动态内容捕获 | 游戏内「游戏辅助」／`⇧F8`；`f` 游戏变量和 `sf` 系统变量中的简单值，锁定与数值筛选 |
| 其他引擎 | 未接入 | 未接入；不会因为支持启动而显示为支持作弊 |

**验证范围**：MV/MZ、VX Ace 已有真实游戏副本验收；XP 使用官方免费示例《KNight-Blade》，VX 使用免费原版《魔女之家》1.09a，验证 XP 菜单／对白、VX 菜单显示，以及两者的金钱／物品／角色／变量与开关编辑、锁定和运行时提取。Ren’Py 使用 8.5.2 SDK 的自编样本。Tyrano 除官方 V5 自编样本外，还用免费作品《放課後ネットミームカルタ》的原剧本验证对白／选项译文和简单变量编辑，但其 Electron 下载包仅在隔离副本调整为 NW.js 宿主后测试，**不代表 Electron 原包能够直接启动**。上述译文显示验收使用预制词典，不等于已调用用户的付费 AI 服务。所有实测仅代表对应样本，不能视为全作品兼容承诺。

**已知边界**：《Star Stealing Prince》3.2 在当前 mkxp-z／Ruby 上存在旧脚本语法错误，移除辅助后仍复现，尚不能正常进入游戏。Ren’Py 7／Python 2、其他自改引擎与特殊插件没有普遍兼容保证。Tyrano 的 Electron／ASAR 封装没有自动转换支持，现有接入面向可直接使用 NW.js 打开的目录。

## 翻译

- 支持原文 → 译文的 JSON 对象，包括此结构的 MTool 译文；嵌套格式、注释和控制符不匹配会被拒绝，不自动猜测格式。
- 「提取游戏文本」按引擎选择提取方式。MV/MZ 读取数据库和事件；RGSS 需先应用辅助、通过启动器进入游戏一次，再返回提取。Ren’Py 源码解析主动跳过 Python、界面及多行代码块；归档和复杂语法用运行时捕获。Tyrano 跳过脚本／HTML 标签块；文字选项可由运行时捕获。
- 自动翻译需要填写兼容聊天补全请求的**完整接口地址**、模型和目标语言；可使用自选 AI 服务。远程接口只允许 HTTPS，本机接口允许 HTTP。密钥保存在 macOS 钥匙串，不写进游戏目录。游戏文字会发送到所填服务，可能产生费用。
- 可暂停继续、仅重试失败项、搜索和手动修订。逐条保存；成功译文不重复请求，重新提取不会覆盖已有修订。游戏控制符与占位符必须保留，包括 Ren’Py 的插值和文字标签。
- 「跟随游戏补译」处理游戏显示时捕获的未命中文字，更新本地缓存；需要启动器保持开启。暂停或退出后，游戏继续显示已有译文或原文。现有画面通常在下次重绘时更新。
- RGSS 逐字对白在拆字之前翻译；中文、日文及其标点的测量与绘制使用一致字体。开启翻译时，将 macOS 自带的 Arial Unicode 字体缓存到启动器数据目录的 `assist-fonts/`，作为额外素材路径加载，不写进游戏目录或随应用分发；关闭翻译后不再追加该路径。缓存损坏或存在不安全链接时停止启动，不覆盖可疑文件。
- Tyrano 运行时不翻译、不捕获 `iscript`／HTML 块内的文本，避免把程序代码误当成台词。
- 图片文字、自绘字形、动态拼接及部分插件文字不保证完整覆盖。未命中时保留原文，不以翻译失败阻止游戏。

译文目录位于数据根目录的 `translations/<游戏身份>.json`，接口配置为 `translation-service.json`。身份结合规范目录与引擎特征数据校验：MV/MZ 使用入口和系统数据，RGSS 使用脚本数据或对应版本归档，Ren’Py 使用剧本／归档（不含缓存、存档和辅助入口），Tyrano 使用引擎与场景特征。游戏移动或特征文件改变后，不会仅按游戏库编号套用旧缓存。

## 作弊

**请先备份存档。** 修改可能改变剧情并写入存档；关闭或移除辅助不能撤销已改动的金钱、物品、角色属性或剧情状态。`sf` 是跨存档的系统变量，修改影响也可能跨存档。

- MV/MZ、Tyrano：点击游戏右上角的「游戏辅助」或按 `⇧F8`。面板会阻止输入传入游戏，修改需要确认。
- RGSS、Ren’Py：应用辅助后，通过启动器进入游戏，再回详情页的「作弊工具」。普通输入框编辑数字或文字，开关编辑布尔值；确认后发送到游戏，并显示游戏回执。连接过期或尚在标题画面时不能编辑。
- 数值查找支持已知／未知初始值，以及增加、减少、变化、未变化的逐次筛选；比较每次查找时的快照，不是扫描整个进程内存。列表最多显示前 100 条，可按名称、键或数值搜索。
- 修改并锁定会周期性维持目标值；普通修改会清除该项旧锁定。可逐项解锁或解除全部锁定。新游戏／读档会解除旧锁定与搜索，不会把上一局的锁强行套到新状态。
- RGSS 仅对公开状态操作；物品、金钱和角色等级等遵守引擎范围，生命／魔力等不超过当前上限。Ren’Py 不执行任意 Python，Tyrano 不执行任意 JavaScript，只接入简单值与受限路径。
- MV/MZ 的地图传送、事件执行和战斗操作会检查当前场景和忙碌状态，并有额外确认；自定义插件仍可能影响行为。其他引擎不会显示尚未实现的 MV/MZ 专属工具。

## 应用与移除

翻译和作弊独立启用。退出游戏后点击「应用到游戏」；不替换原始数据库或剧本。译文修订后可重新应用；跟随补译会自动更新运行字典。

- **MV/MZ、Tyrano**：在入口页面末尾加载独立脚本；辅助文件与原入口备份放在入口旁的 `.tsumigeya-assist/`。移除时校验并逐字节恢复页面。
- **RGSS**：游戏目录只添加 `.tsumigeya-assist/`；启动计划在已有预加载之后追加辅助，不改 `Scripts`／游戏归档，必须从本启动器启动。移除后下一次启动不再追加辅助。
- **Ren’Py**：在 `game/` 添加独立 `zz_tsumigeya_assist.rpy` 和 `.tsumigeya-assist/`，保留原剧本。辅助状态留在独立模块，初始化局部变量不加入游戏存档。移除时同时清理本工具的入口与编译文件。

应用前会核对游戏身份、拥有的脚本及原入口；存在外部篡改、同名文件、未知文件或不安全符号链接时停止覆盖／清理。运行中不能安装、更新或恢复；移除保留启动器的译文目录。原生状态命令含当前游戏身份、运行会话与短有效期，过期及读档前的命令不会写入新会话。

游戏继续运行不依赖启动器存活；但关闭启动器后，RGSS／Ren’Py 的状态编辑界面和所有引擎的跟随补译会停止，游戏保留已加载的辅助和已有字典。

## 离线辅助

「辅助」页里的离线改写块，**只在 NScripter 与 RPG Maker 2000/2003 出现**：这两个引擎是 C++ 解释器，没有可注入的脚本层，改文件是唯一手段。其余引擎使用游戏内注入面板，不会显示这一块。

写前在同目录生成 `.tsumigeya-bak` 备份，已有备份不覆盖；游戏运行中禁止写回。

- **NScripter**：读 `0.txt` / `00.txt` / `nscript.dat`（后者每字节 XOR 0x84），只替换整行以引号开头的正文；命令行、注释与 `*label` 不动，保留每行原本的换行符。写回沿用原编码；原编码装不下中文时落到 UTF-8 并报告，需把游戏的 `--enc` 参数改成同一编码。
- **RPG Maker MZ**：`save/*.rmmzsave` 是 `LZString.compressToBase64(JsonEx.stringify(...))`。保留 `JsonEx` 的 8 位 hash 前缀，只改 JSON 里的标量；类型不符的替换一律拒绝。
- **RPG Maker XP / VX / VX Ace**：`.rvdata2` / `.rxdata` 是 Ruby Marshal。不做重新序列化（那会把共享引用展开成多份），只扫描标量的字节区间原位替换，其余字节含 `@n` 引用不动。只能改数字、布尔值和字符串。
- **RPG Maker 2000 / 2003**：`RPG_RT.ldb` 是 LCF 容器，可提取角色、技能、物品、敌人、地形、状态、公共事件、开关、变量的名称与说明。**只读**，写回需要重建整棵 chunk 树并逐层重算长度，当前不做。

验证范围：NScripter 覆盖明文、加密与三种编码；MZ 与 RGSS 只在生成样本上验证，**没有真实作品存档**。EasyRPG 的 `.lsd` 存档与吉里吉里的 `.xp3` 尚未实现。

## CLI 验收

```bash
swift run tsumigeya-cli assist inspect <游戏目录>
swift run tsumigeya-cli assist extract <游戏目录>
swift run tsumigeya-cli assist install <游戏目录> --translation --cheats
swift run tsumigeya-cli assist state <RGSS或RenPy目录>
swift run tsumigeya-cli assist command <RGSS或RenPy目录> set <变量键> <JSON值>
swift run tsumigeya-cli assist restore <游戏目录>
swift run tsumigeya-cli offline script-inspect <游戏目录>
swift run tsumigeya-cli offline script-apply <游戏目录> <字典.json>
swift run tsumigeya-cli offline save-inspect <存档路径>
swift run tsumigeya-cli offline save-set <存档路径> party._gold 4200
swift run tsumigeya-cli offline ldb-inspect <RPG_RT.ldb>
node --test Tests/TsumigeyaTests/Assist/runtime.test.cjs
python3 Tests/TsumigeyaTests/Assist/renpy_runtime_test.py
ruby Tests/TsumigeyaTests/Assist/rgss_runtime_test.rb
```

`assist install` 首次安装使用空字典，重复安装保留已有译文；实际导入、翻译和应用译文请使用界面。`assist command` 返回发送编号，不代表已经修改成功；用 `state` 核对 `ack` 与 `error`。请在独立游戏副本和数据目录验收，不用私人存档验证破坏性操作。
