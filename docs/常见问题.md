# 常见问题

[返回项目首页](../README.md) · [下载最新版](https://github.com/Yometenma/Tsumigeya/releases/latest) · [报告问题](https://github.com/Yometenma/Tsumigeya/issues/new/choose)

## 安装与更新

### 支持哪些 Mac？

当前安装包需要 **macOS 26 或更新版本和 Apple Silicon**。不提供 Intel 安装包，也不提供 Windows 或 Linux 的原生版。

<a id="first-launch"></a>

### 首次打开提示“无法验证开发者”或“应用已损坏”怎么办？

先确认安装包来自本仓库的 Releases，而不是不明来源的转载。当前应用仅做 ad-hoc 签名，没有 Developer ID 分发签名，也未经过 Apple 公证，因此可能被 Gatekeeper 拦截。

如果信任来源，可对已经放入「应用程序」的应用执行：

```bash
xattr -dr com.apple.quarantine /Applications/Tsumigeya.app
```

这会移除该应用的下载隔离标记，不是公证或安全证明。**不要关闭系统整体安全保护。** 如果提示仍然存在，不要把所有问题都归因于隔离标记；重新下载安装包，并检查下载是否完整。

发布附件中的 `SHA256SUMS.txt` 记录安装包校验值。在下载目录中可查看安装包的 SHA-256，并与该版本的校验文件逐项比较：

```bash
shasum -a 256 Tsumigeya-*.dmg
```

如果应用未安装在 `/Applications`，命令中的路径也需要相应调整。

### 如何更新？会丢游戏库吗？

退出 Tsumigeya，下载新版 DMG，再替换「应用程序」中的旧应用。应用数据与 `.app` 分开存储，当前版本使用以下目录：

```text
~/Library/Application Support/Tsumigeya/
```

更新前仍建议备份应用数据和真实游戏存档。不同历史版本的迁移说明以对应 Release 为准；不要删除应用数据目录来“清理旧版本”。

## 游戏与运行时

### 它能运行任意 Windows 游戏吗？

不能。Tsumigeya 不是通用的 Windows 模拟器，而是识别特定游戏引擎，并使用可用的 macOS 运行时启动游戏。Unity、RPG Developer Bakin、WOLF RPG Editor 当前只识别，不代为启动。

识别引擎并不等于保证兼容。插件、脚本扩展、加密方式和依赖都可能影响结果。具体范围见 [游戏兼容性](../README.md#游戏兼容性)。

### 应该选择哪个文件？可以直接添加 ZIP 吗？

先把游戏完整解压到一个稳定的位置，再在「添加游戏」中选择游戏目录内的任意文件，不必一定是可执行文件，`.app` 包也可以。应用会按目录结构识别引擎；请核对识别出的目录，不要单独复制一个文件而丢掉其余数据。

如果自动识别不正确，确认目录结构完整，并在添加时检查引擎。诊断前先不要移动或重命名游戏目录。

### 有很多游戏，可以一次添加吗？

开发版提供「批量入库」：选集合目录，等待扫描，再逐项核对引擎、标题并勾选。保存前会重新检查目录和重复项；任一选中项不合法时整个批次都不写入。依赖缺失会明确提示，入库后仍需到运行时页安装；只识别的引擎不能直接启动。

扫描有三层深度、2000 个目录和 200 个候选的上限，不扫描 ZIP、不跟随子目录符号链接，也不会深入已经识别出的游戏。提示达到上限时可分小目录扫描。不能识别的游戏请使用单个添加，手工确认引擎。不会自动请求或选择 DLsite 作品信息。

### 游戏搬家后需要删除重加吗？

不需要。开发版可在详情的更多菜单使用「重新定位游戏目录…」。先退出游戏，选择移动后的同一游戏目录；识别引擎必须匹配，还需手工确认作品身份，因为同一引擎不能证明是同一部游戏。原编号、分类、元数据和游玩记录会保留。错误目录或已关联其他记录的目录不会保存。

该操作不移动文件，也不搬移或合并存档。原游戏若把存档放在独立位置，仍需按实际存档位置迁移和备份。标题隐藏开启时，批量入库和重新定位暂不可操作。

### 启动诊断会做什么？

在游戏详情的「更多」菜单中选择「检查启动条件」，可以查看游戏目录是否存在、当前引擎是否支持启动、运行时二进制是否找到且有执行权限，以及本次会使用的工作目录和参数。它只检查，不会启动游戏；对 mkxp-z 也不会因为诊断而修改 Game.ini、创建路径别名或覆盖 mkxp.json。

如果诊断提示目录不存在，请使用「重新定位游戏目录」；如果提示运行时缺失或没有执行权限，请到「运行时」页安装或修复。进程已经运行时，诊断只提示不能重复启动，不会替你停止游戏。

### 运行时装好了，为什么还是启动失败？

运行时安装完成只代表依赖已经准备好，不代表具体游戏兼容。可按顺序检查：

1. 游戏是否完整解压，添加的路径是否仍存在。
2. 引擎识别是否正确，对应运行时是否安装完成。
3. 「运行信息」中的引擎参数、运行时版本和路径是否合理。
4. 同一游戏是否已在运行，是否出现初始化错误或游戏自己的报错窗口。

反馈时请提供应用版本、系统版本、芯片、游戏版本、引擎和复现步骤。可以提供公开的 RJ 编号或作品页面，不需要上传游戏本体。

### 可以离线使用吗？

添加本地游戏和管理游戏库不要求先登录 DLsite。已安装的运行时也无需每次重新下载，但作品本身或其启动环境可能仍有网络要求。

安装运行时、抓取 DLsite 作品信息和加载网络封面需要访问相应站点。网络失败时，请检查代理和目标站点的可达性；不要把无法下载依赖直接判断为游戏不兼容。

## 作品信息与存档

### 搜不到作品，或匹配到同名结果怎么办？

在详情页点击「查找作品…」，可以输入作品名、RJ 编号或粘贴 DLsite 作品链接。默认同时搜索成人向同人与一般向，也可手动缩小范围。确实无结果时会尝试清理汉化／版本后缀与下划线；界面会显示尝试过的关键词。中文译名与原名无法可靠对应时，请换用日文原名、英文名或作品链接，不会凭猜测自动匹配。

候选显示封面、作品名、社团和编号，点击「预览」核对详情后再「确认关联此作品」。应用不会自动认定第一条就是你的游戏，正片、追加内容和不同版本仍需核对。获取失败保留候选和关键词；部分分类请求失败时会保留其他分类已找到的候选，并明确提示。网络故障、验证页面与真正无结果分别显示。

作品信息支持完整介绍、发售日期、系列、题材标签、语言、制作／配音、原版支持系统及预览截图，缺失项不臆测。页面标注的语言和支持系统是原版信息，不保证本地汉化包语言或在 Mac 上的实际兼容性。标签、社团、系列、原始作品名及 RJ 编号可用于游戏库搜索。

标题、社团、简介和「更多作品信息」中的字段可手动编辑，刷新同一作品时保留手改内容。更换作品请用详情页的「更换关联…」，预览确认后才替换；旧作品的手改字段不会混入新作品，游戏库名称、分类和存档不变。刷新或换绑失败不替换原有信息。

请求自动按至少 800ms 间隔调度，可取消等待／获取；不会要求用户因普通连续点击而手动等待重试。封面下载失败可重试，不会从游戏素材中随便挑一张当封面。隐私模式同时隐藏候选封面和预览截图。已保存的旧信息不会自动联网升级，点击「刷新信息」可获取新增字段。

### 存档在哪里？“位置未知”和“空存档”有什么区别？

在游戏详情的「存档」页查看。位置取决于游戏和引擎，不一定在 Tsumigeya 的应用数据目录内。

- **位置未知**：应用还不能确定该游戏的存档目录。TyranoScript 和吉里吉里不会自动猜测路径。
- **目录为空或尚无存档**：应用已确定位置，但没有找到可展示的存档。

如果知道实际位置，可点击「选择存档目录…」手动指定。这个操作只记录目录，不会移动或合并文件；目录可以是空的。目录被移动或删除后仍会显示为未知，不会伪装成空存档；点击「在访达中显示」可以打开当前目录，复制按钮会复制完整路径；点击「恢复自动探测」可清除手动指定。游戏运行中不能更改目录。

### 如何备份或迁移？支持云同步吗？

先退出游戏，再从「存档」页导出 ZIP。在目标环境中添加对应游戏、确认存档位置后，使用导入功能恢复。

导出包含整个存档目录，而不只包含常见存档槽；导入会先校验内容，再备份已有文件。导入备份通常以 `.tsumigeya-bak` 结尾，已有同名备份不会被覆盖；如果因此导入失败，应先核对并妥善保存备份，不要直接删除。

当前**没有云同步**，导出的 ZIP 由你自行保管。迁移游戏库时还应另行复制应用数据目录和游戏本体；应用数据、游戏和存档是三件不同的东西。

### 能把界面或日志直接贴进 Issue 吗？

可以，但请先隐藏姓名、个人目录、账号信息、令牌和私人内容。不要附商业游戏本体、付费素材、未公开补丁或私人存档。

截图前可点击顶部的「隐私模式」，或按 `⇧⌘P`，隐藏全部作品封面。在「设置 → 游戏库」或菜单栏的「隐私」菜单中，还可开启「同时隐藏标题」：标题会显示为游戏编号，作品详情、游戏路径、搜索文字与相关错误详情也会隐藏；此时添加、编辑、作品关联和存档导入导出暂不可操作，已有编辑草稿会保留。关闭隐私模式后恢复原有显示，不会修改原始游戏名称或作品信息。

设置会在重启后保留。旧版本中保存过「不显示 R18 封面」的选择会保守地转换为隐藏全部封面的效果；新隐私开关可以明确覆盖该选择。隐私模式不依赖成人分级，也不是系统级的防截图保护：**自定义分类名、访达、系统文件选择窗口和游戏自身窗口不在隐藏范围内**。公开截图前仍请自行检查并裁切或遮挡私人内容。
