# 常见问题

[返回项目首页](../README.md) · [下载最新版](https://github.com/Yometenma/Tsumigeya/releases/latest) · [报告问题](https://github.com/Yometenma/Tsumigeya/issues/new/choose)

## 安装与更新

### 支持哪些 Mac？

当前安装包需要 **macOS 26 或更新版本和 Apple Silicon**。不提供 Intel 安装包，也不提供 Windows 或 Linux 的原生版。

<a id="first-launch"></a>

### 首次打开提示“无法验证开发者”或“应用已损坏”怎么办？

先确认安装包来自本仓库的 Releases，而不是不明来源的转载。当前应用仅做 ad-hoc 签名，没有 Developer ID 分发签名，也未经过 Apple 公证，因此可能被 Gatekeeper 拦截。

如果信任来源，可对已经放入「应用程序」的应用执行：

```bash
xattr -dr com.apple.quarantine /Applications/Tsumigeya.app
```

这会移除该应用的下载隔离标记，不是公证或安全证明。**不要关闭系统整体安全保护。** 如果提示仍然存在，不要把所有问题都归因于隔离标记；重新下载安装包，并检查下载是否完整。

发布附件中的 `SHA256SUMS.txt` 记录安装包校验值。在下载目录中可查看安装包的 SHA-256，并与该版本的校验文件逐项比较：

```bash
shasum -a 256 Tsumigeya-*.dmg
```

如果应用未安装在 `/Applications`，命令中的路径也需要相应调整。

### 如何更新？会丢游戏库吗？

退出 Tsumigeya，下载新版 DMG，再替换「应用程序」中的旧应用。应用数据与 `.app` 分开存储，当前版本使用以下目录：

```text
~/Library/Application Support/Tsumigeya/
```

更新前仍建议备份应用数据和真实游戏存档。不同历史版本的迁移说明以对应 Release 为准；不要删除应用数据目录来“清理旧版本”。

## 游戏与运行时

### 它能运行任意 Windows 游戏吗？

不能。Tsumigeya 不是通用的 Windows 模拟器，而是识别特定游戏引擎，并使用可用的 macOS 运行时启动游戏。Unity、RPG Developer Bakin、WOLF RPG Editor 当前只识别，不代为启动。

识别引擎并不等于保证兼容。插件、脚本扩展、加密方式和依赖都可能影响结果。具体范围见 [游戏兼容性](../README.md#游戏兼容性)。

### 应该选择哪个文件？可以直接添加 ZIP 吗？

先把游戏完整解压到一个稳定的位置，再在「添加游戏」中选择游戏目录内的任意文件，不必一定是可执行文件，`.app` 包也可以。应用会按目录结构识别引擎；请核对识别出的目录，不要单独复制一个文件而丢掉其余数据。

如果自动识别不正确，确认目录结构完整，并在添加时检查引擎。诊断前先不要移动或重命名游戏目录。

### 运行时装好了，为什么还是启动失败？

运行时安装完成只代表依赖已经准备好，不代表具体游戏兼容。可按顺序检查：

1. 游戏是否完整解压，添加的路径是否仍存在。
2. 引擎识别是否正确，对应运行时是否安装完成。
3. 「运行信息」中的引擎参数、运行时版本和路径是否合理。
4. 同一游戏是否已在运行，是否出现初始化错误或游戏自己的报错窗口。

反馈时请提供应用版本、系统版本、芯片、游戏版本、引擎和复现步骤。可以提供公开的 RJ 编号或作品页面，不需要上传游戏本体。

### 可以离线使用吗？

添加本地游戏和管理游戏库不要求先登录 DLsite。已安装的运行时也无需每次重新下载，但作品本身或其启动环境可能仍有网络要求。

安装运行时、抓取 DLsite 作品信息和加载网络封面需要访问相应站点。网络失败时，请检查代理和目标站点的可达性；不要把无法下载依赖直接判断为游戏不兼容。

## 作品信息与存档

### 搜不到作品，或匹配到同名结果怎么办？

可以手动输入 RJ 编号，也可以按作品名搜索。搜索结果需要自行选择，应用不会自动认定第一条就是你的游戏。先确认正片、追加内容和不同版本是否对应。

标题、社团、简介等字段可以手动编辑；手动修改的字段在刷新作品信息时保留。没有成功获取封面时，应用显示占位图，不会从游戏素材中随便挑一张当封面。

### 存档在哪里？“位置未知”和“空存档”有什么区别？

在游戏详情的「存档」页查看。位置取决于游戏和引擎，不一定在 Tsumigeya 的应用数据目录内。

- **位置未知**：应用还不能确定该游戏的存档目录。TyranoScript 和吉里吉里目前属于未实现定位的范围。
- **目录为空或尚无存档**：应用已确定位置，但没有找到可展示的存档。

不要为了解决“位置未知”而随意移动文件；先确认引擎和定位规则。

### 如何备份或迁移？支持云同步吗？

先退出游戏，再从「存档」页导出 ZIP。在目标环境中添加对应游戏、确认存档位置后，使用导入功能恢复。

导出包含整个存档目录，而不只包含常见存档槽；导入会先校验内容，再备份已有文件。导入备份通常以 `.tsumigeya-bak` 结尾，已有同名备份不会被覆盖；如果因此导入失败，应先核对并妥善保存备份，不要直接删除。

当前**没有云同步**，导出的 ZIP 由你自行保管。迁移游戏库时还应另行复制应用数据目录和游戏本体；应用数据、游戏和存档是三件不同的东西。

### 能把界面或日志直接贴进 Issue 吗？

可以，但请先隐藏姓名、个人目录、账号信息、令牌和私人内容。不要附商业游戏本体、付费素材、未公开补丁或私人存档。

当前封面隐私过滤尚未实现，截图可能包含不适合公开的游戏封面。建议先裁切或遮挡后再提交。
