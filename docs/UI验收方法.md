# UI 验收

## 执行

Windows 不能验证 SwiftUI。连接 Mac，在仓库的 `mac-native/` 中执行：

日常编译与默认测试：

```bash
swift build
swift test --no-parallel
```

以下是独立的快照验收入口，会创建真实窗口并输出图片：

```bash
mkdir -p ../.dev-scratch/ui
.build/debug/Tsumigeya --snapshot "$PWD/../.dev-scratch/ui"
```

需要本地查看时，再用 `scp` 取回 PNG。不要把快照产物提交到仓库。

快照复用生产视图，在屏幕外的真实 `NSWindow` 中布局后抓取像素；不能改回直接用 `ImageRenderer` 渲染复杂容器，否则可能得到空白或占位图。布局在主线程推进，不用信号量阻塞。

## 日常编译与窗口渲染测试

`swift build` 只编译，不打开应用界面。默认 `swift test --no-parallel` 包含 5 项真实窗口渲染回归（13 种状态）。测试及 `--snapshot` 可能短暂显示窗口，负坐标不保证静默，SSH 会话也不与用户桌面隔离。

当前游戏库入口是 `RootView` 的侧边栏与详情布局；旧整库卡片／列表组件及失效开关已移除，回归检查当前入口可达的视图。判断旧残留时应同时核对生产调用链、测试构造的视图、进程路径和安装版本，不能只凭文件仍可编译或窗口外观判断。

## 远程真窗口操作

- 使用隔离数据目录和应用副本，不以正式游戏库验写入、换绑和失败重试。同名应用同时运行时，先核对进程编号与可执行路径，避免误操作正式窗口。
- 录屏与辅助功能分别核对；权限由用户在系统界面授权，脚本不得修改授权数据库。开关状态或一次成功的窗口读取不能单独证明全部权限正常。
- 截图全黑或控件读取异常时，先检查桌面是否锁定；锁屏后停止交互，不把异常直接归因于权限或应用缺陷，也不尝试自动解锁。
- 按钮调用返回成功不等于流程通过：结合真实屏幕检查图片与布局，并检查确认前后实际落盘的数据、状态和本地名称。图片缓存命中、离线加载、失败重试、放大与关闭需用真实下载验证。

## 快照检查

- 覆盖游戏库选中 / 未选中 / 无结果、运行时、详情、编辑、存档、运行信息、手动存档目录（未知 / 有效空目录）、最小窗口、浅色、设置分组和长标题。部分页面需要游戏数据，不能仅以固定图片张数判通过。
- 命令返回成功、图片非纯色只是最低要求，仍需逐张检查空白、裁切和操作遮挡。
- 空白检测的回归测试要包含纯色、单点噪声、中央稀疏内容对照，防止检测器假通过。
- 入库、存档等预览使用临时数据副本，不能为了验 UI 改写正式游戏库或用户偏好。

**限制**：SSH 下系统截图受权限限制；离屏 `AsyncImage` 不下载封面，侧边栏材质也可能失真。快照不能证明封面正常、交互正确或观感合格。

## 交互约束与真窗口清单

| 范围 | 必须检查 |
|---|---|
| 导航与筛选 | 顶层为游戏库、运行时、设置；分类 / 搜索 / 侧边栏切换不因无结果而消失；无结果可清除筛选 |
| 游戏库与详情 | 侧边栏选择、收起 / 展开、连续切游戏和标签不串状态；启动 / 停止与当前游戏对应；长标题不遮挡操作 |
| 详情分工 | 概览为作品信息，存档为归档操作，运行信息为路径 / 进程 / 引擎参数；主要操作保持可见 |
| 编辑 | 模态草稿；关闭未保存内容需确认，取消放弃仍保留草稿；保存后重开一致；分类即时保存需明确说明 |
| 存档 | 未知位置 / 空 / 有存档分别显示；可手动指定目录且不移动文件；失效目录仍为未知；已确定目录可在访达中显示并复制完整路径；运行中禁用目录修改和导入导出；用真实归档验数据，不只看按钮 |
| 运行时 | 验证 Wine 安装、失败、取消及重试；卸载需确认，运行中不能卸载；旧的仅识别引擎不再单独展示 |
| Wine | 真实 32／64 位窗口、入口选择、Windows 环境设置；两个游戏同时运行时停止一个不影响另一个；退出启动器后游戏继续，不能仅以监护进程存活判成功 |
| 设置 | 分组切换与重启后持久化；未实现项收起且不可编辑；不提供无效的同步开关 |
| 长正文切换 | 对有较长作品介绍的游戏连续切换，确认窗口不因全文排版整体停住；正文区域保持可滚动、可选择复制，截图和封面仍按需加载。现场观感不能由离屏快照代替 |
| 详情切换 | 从真实侧边栏连续切换有／无作品资料的不同游戏，分别检查首次加载与缓存命中；慢目录说明文件扫描不阻塞点击，晚到提示及封面不串页。使用大尺寸图片核对缩略图／详情清晰度、比例、放大与重试；切回已缓存游戏不重复解码同一尺寸。现场性能采样与操作观感单独验收，单测及离屏渲染不代替 |
| 封面 | 真窗口验证下载、比例和错误状态，不能把占位图算成功 |
| 作品查找 | 名称／RJ／链接统一输入；修改关键词不改变库内标题；候选封面、社团与作品页可核对；预览后才确认；换绑明确告知字段替换；失败保留关键词与候选，取消及关闭后晚到结果不得回写；成人向与一般向各用真实页面验抓取 |
| 作品信息语言 | 优先／回退设置可保存，单部及批量实际使用；同一作品中英文标题和正文不同，切换语言不误用旧缓存；网站菜单语言不能被当作所有字段的实际语言 |
| 外部作品信息 | 未授权不调用；普通聊天接口不伪装联网；候选不自动关联；真实页面正文与分享封面可读取；来源引文可核对、字段可选和手改；确认前不落盘，取消／删除／编号复用不回写；手动填写不需接口，保存不改原游戏名；模拟接口与真实付费模型验收分别说明 |
| 独立搜索与局域网 | Tavily／SearXNG／自定义方式切换、独立密钥保存；普通聊天模型无需工具调用即可搜索后整理；候选摘要不直接落盘；认证失败不自动重试或切换服务；局域网授权需确认，取消不授权，改地址或撤销后旧任务失效；模型与搜索互不授权，不放宽网页和图片限制；兼容选项实际进入请求，真实服务与模拟服务验收分别说明 |
| 批量作品信息 | 当前筛选范围与仅未关联／刷新全部模式正确；唯一编号自动补全、多编号与搜索候选不自动关联；可逐项确认、暂停继续和仅重试失败项；已保存范围明确，失败不阻断队列；关闭后晚到结果不落盘，删除或编号复用不串数据 |
| 丰富作品信息 | 发售日期、系列、标签、语言、制作／配音、原版系统和长介绍可读；介绍展开／收起，截图放大／关闭；已缓存封面与预览在重新打开页面和离线时仍可显示；新字段手改后刷新不覆盖；刷新失败仍显示旧信息 |
| 自动分类 | 已保存作品类型归类，预览不改分类；旧归属保留，手动增删刷新后仍在；类型变化只替换自动部分；恢复自动需确认；分类重命名不丢来源，删除后刷新不复活；重新打开应用与筛选结果一致 |
| 游戏移除 | 运行中阻止；资料、游玩记录或游戏库备份失败时说明已保存范围，游戏记录保留并可重试；清理失败后晚到抓取不回写；成功后编号复用不继承原资料、分类和人工调整 |
| 单部添加 | 从顶部添加或 `⌘O` 打开无装饰侧栏的向导，确认选择文件、引擎确认、命名保存与取消仍可用 |
| 批量入库 | 选择目录、扫描取消与重试、候选逐项选择及标题编辑；已入库目录不可勾选；重复标题、扫描后目录变化和备份失败不部分入库；上限和不可读目录明确提示 |
| 重新定位 | 更多菜单打开、选择新目录、同引擎与身份确认；运行中禁用、错误引擎拒绝；保存后重开路径正确，编号及旁挂数据不变 |
| 翻译与作弊 | 独立副本中分别确认 MV/MZ、RGSS、Ren’Py 和 Tyrano 识别，以及启动／翻译／作弊能力区分；两个开关互不依赖；接口保存及重试发送确认；提取、导入导出、修订、暂停继续与跟随补译；可见游戏文字实际替换；作弊面板输入不触发游戏、锁定与逐次搜索、读档解除临时辅助；原生状态面板核对数字输入、布尔开关、中文文字、二次确认与游戏回执；RGSS 保留已有预加载，Ren’Py 可正常存读档，读档解除锁定；运行中拒绝安装恢复，网页入口恢复字节一致、原生辅助不残留；切游戏不串会话 |
| 启动诊断 | 启动失败后可打开诊断；目录、引擎、运行时权限和启动计划逐项显示；mkxp-z 诊断不改写 Game.ini 或 mkxp.json |

旧隐私设置兼容回归使用窗口渲染像素识别当前侧边栏、详情、编辑和搜索结果中的原标题；旧设置不应再遮挡内容或限制操作。这不等于验证真实下载与交互。

快捷键：`⌘O` 添加、`⌘F` 搜索、`Return` 详情启动 / 停止、`⌘⌥S` 收起 / 展开侧边栏、`⌘S` 保存编辑。输入控件和弹窗应优先处理自己的按键。

后续重点：补齐编辑草稿的交互自动化；状态和绑定测试不能代替真实窗口交互。验收结果写提交说明，不另建“本轮”报告。
