# UI 验收

## 执行

Windows 不能验证 SwiftUI。连接 Mac，在仓库的 `mac-native/` 中执行：

```bash
swift build
swift test
.build/debug/Tsumigeya --snapshot /tmp/tsmg-ui
```

需要本地查看时，先建 `.dev-scratch/ui/`，再用 `scp` 取回 PNG。不要把快照产物提交到仓库。

快照复用生产视图，在屏幕外的真实 `NSWindow` 中布局后抓取像素；不能改回直接用 `ImageRenderer` 渲染复杂容器，否则可能得到空白或占位图。布局在主线程推进，不用信号量阻塞。

## 快照检查

- 覆盖游戏库选中 / 未选中 / 无结果、运行时、详情、编辑、卡片库、存档、运行信息、最小窗口、浅色、设置分组和长标题。部分页面需要游戏数据，不能仅以固定图片张数判通过。
- 命令返回成功、图片非纯色只是最低要求，仍需逐张检查空白、裁切和操作遮挡。
- 空白检测的回归测试要包含纯色、单点噪声、中央稀疏内容对照，防止检测器假通过。
- 卡片 / 列表预览使用临时设置副本，不能为了验 UI 改写用户偏好。

**限制**：SSH 下系统截图受权限限制；离屏 `AsyncImage` 不下载封面，侧边栏材质也可能失真。快照不能证明封面正常、交互正确或观感合格。

## 交互约束与真窗口清单

| 范围 | 必须检查 |
|---|---|
| 导航与筛选 | 顶层为游戏库、运行时、设置；分类 / 搜索 / 视图切换不因无结果而消失；无结果可清除筛选 |
| 游戏库与详情 | 列表切换、卡片进入 / 返回、连续切游戏和标签不串状态；启动 / 停止与当前游戏对应；长标题不遮挡操作 |
| 详情分工 | 概览为作品信息，存档为归档操作，运行信息为路径 / 进程 / 引擎参数；主要操作保持可见 |
| 编辑 | 模态草稿；关闭未保存内容需确认，取消放弃仍保留草稿；保存后重开一致；分类即时保存需明确说明 |
| 存档 | 未知位置 / 空 / 有存档分别显示；运行中禁用导入导出；用真实归档验数据，不只看按钮 |
| 运行时 | 区分可安装 / 仅识别；验证进度、失败、取消及重试；卸载需确认，运行中不能卸载 |
| 设置 | 分组切换与重启后持久化；未实现项收起且不可编辑；不提供无效的同步开关 |
| 封面 | 真窗口验证下载、比例和错误状态，不能把占位图算成功 |
| 批量入库 | 选择目录、扫描取消与重试、候选逐项选择及标题编辑；已入库目录不可勾选；重复标题、扫描后目录变化和备份失败不部分入库；上限和不可读目录明确提示 |
| 重新定位 | 更多菜单打开、选择新目录、同引擎与身份确认；运行中禁用、错误引擎拒绝；保存后重开路径正确，编号及旁挂数据不变；隐私切换不能泄露路径 |
| 启动诊断 | 启动失败后可打开诊断；目录、引擎、运行时权限和启动计划逐项显示；mkxp-z 诊断不改写 Game.ini 或 mkxp.json；隐私模式不泄露路径和参数 |
| 隐私 | 顶栏与 ⇧⌘P 切换一致；只隐藏封面时保留标题；同时隐藏标题时检查列表、卡片、详情、搜索结果、编辑、移除确认和路径悬浮提示；下载中切换不能闪回原图；重启保留偏好，关闭后恢复原文与编辑草稿 |

隐私回归测试通过实际窗口的渲染像素识别文字，先确认原文可见，再检查隐藏与恢复；这不等于验证了屏幕阅读器或真实封面下载。

快捷键：`⇧⌘P` 隐私模式、`⌘O` 添加、`⌘F` 搜索、`Return` 详情启动 / 停止、`Esc` 卡片详情返回、`⌘S` 保存编辑。输入控件和弹窗应优先处理自己的按键。

后续重点：补齐编辑草稿的交互自动化；状态和绑定测试不能代替真实窗口交互。验收结果写提交说明，不另建“本轮”报告。
