# 作品信息获取

本文对应 v3.0.0 的作品信息功能。信息补全不改变游戏启动兼容性，也不会下载游戏本体。

## 选择资料语言

在 **设置 → 作品信息** 中设置「作品信息优先语言」和「缺失时回退语言」。支持简体中文、繁体中文、日文、英文、韩文；默认简体中文优先、日文回退，也可关闭回退。

- 单部查找、候选预览、刷新和批量 DLsite 补全使用同一偏好。切换偏好不会自动联网重写已保存资料；已有作品请手动刷新。
- 请求明确指定 DLsite 商品页语言，缓存按 RJ 和请求语言分别保存，避免中文请求命中先前的英文缓存。旧缓存保留，不当作新语言缓存使用。
- 目标商品页不可用或明确返回其他页面语言时，尝试同一 RJ 的回退语言；搜索无结果时也可尝试回退语言。断网、验证页面和服务故障不会被伪装成“没有此语言”。
- **页面语言不等于游戏语言**。DLsite 有些商品只翻译了网站导航，标题或正文仍是原文；这类字段保留网站实际内容，不凭菜单语言声称整段介绍已翻译。页面未标明语言时显示“未标明”。
- 不自动切换到另一个 RJ 的翻译版、追加内容或重制版；不同编号仍需你核对并确认关联。

AI 整理也使用作品信息优先语言，但只翻译或整理来源中的文字，不据此填入“游戏支持语言”。界面语言与游戏翻译接口保持独立。

## 不在 DLsite 上的游戏

先正常添加本地游戏，再在 **游戏详情 → 查找作品／补全或更换资料 → 其他游戏 · AI／手动** 选择操作。

### 方式一：指定公开页面

1. 在设置中配置作品信息接口与模型，将密钥填入密钥框后单独保存。
2. 粘贴官网或商店的 **HTTPS 商品页链接**，确认发送内容和费用提示，点击「读取并整理页面」。
3. 应用读取必要正文，再交给模型整理。模型只能提交带原页面引文的字段，无法核对的字段会被忽略；日期还需保留来源原文，不能凭空推断。
4. 在预览中核对标题、开发商／发行商、介绍、日期、系列、标签、语言、制作／配音及原版系统等资料，选择需要的字段，也可直接修改。
5. 点击「确认保存所选信息」才写入。取消或关闭不修改原信息。

封面来自页面自带的分享图片信息，模型返回的图片地址不会被采纳，也不会生成图片冒充官方封面。可取消保存封面，或手动填写公开 HTTPS 图片地址；不读取本机图片或游戏素材。第三方图片不跟随重定向，因此某些防盗链或跳转图片可能无法显示。

目前只读取公开、可直接访问的 UTF-8 HTML，不执行网页脚本、不携带浏览器登录 Cookie。登录页、年龄验证、反爬验证、动态加载、正文过长或网页禁止访问时可能失败；请换用另一个公开页面，或手动填写。

### 方式二：按游戏名联网查找

在 **设置 → 作品信息 → 搜索来源** 选择搜索方式，再输入游戏名称，可补充开发商、年份等线索。

- **模型原生联网**：需要 Responses 接口及模型服务支持 `web_search`，候选只采纳接口返回的来源引用。
- **独立搜索 · Tavily**：单独保存搜索密钥；搜索地址留空使用官方搜索接口。应用按作品信息优先语言发出一次基础搜索（偏好而非严格语言过滤），不启用自动搜索参数、不请求 AI 答案或完整网页正文，候选最多十二条，界面可选三／五／十条。
- **独立搜索 · SearXNG**：填写实例完整搜索地址，实例须启用 JSON 输出；是否需要密钥取决于你的服务。公共实例可能限流或关闭 JSON。
- **独立搜索 · 自定义接口**：支持 GET 查询参数或 POST JSON，配置关键词参数名和点号分隔的结果字段路径。默认读取 `results` 数组及每项的 `title`、`url`、`content`；结果数组路径留空表示根数组。附加参数只填非敏感 JSON，需单独确认保存。认证仅支持独立 Bearer 密钥，需要其他认证方式的服务请通过自己的转换服务接入，不能把密钥放进查询参数。
- **关闭联网搜索**：仍可指定页面整理或手动填写。

独立搜索由应用执行，**普通聊天模型不需要支持工具调用或自己联网**。即使模型支持工具调用，当前也按“搜索 → 人工选来源 → 模型整理”的固定流程执行，不让模型自主循环搜索。每次操作只调用所选搜索服务，失败不自动重试或切换收费服务。

候选显示标题、来源链接和可用摘要，只接受公开 HTTPS 链接并去重，不从模型正文随意提取网址，不自动认定首条就是你的游戏。搜索摘要只是辨认线索，不直接保存成正式资料；选中来源后，才读取页面并由模型生成待确认资料。单独搜索不要求先配置模型，但整理页面仍需要模型。

### 方式三：完全手动填写

点击「手动填写…」即可录入资料，不需要接口或密钥，也不联网。标题为必填项，其余未知字段可留空。保存后仍可从「编辑游戏」修改。

## 接口、凭据与费用

作品信息接口和游戏翻译接口分开配置，地址需要填写完整请求路径。例如：

```text
兼容聊天接口：https://api.example.com/v1/chat/completions
Responses 接口：https://api.example.com/v1/responses
```

上面的地址仅表示格式，不是可直接使用的服务。模型名称与搜索支持以你的服务商为准，不内置默认付费模型。默认仅接受 HTTPS，或明确配置的 `localhost`／`127.0.0.1` 本机 HTTP 服务；局域网 HTTP 需要下述单独授权。接口地址不能包含账号、密码或查询参数，密钥请放入专用密钥框。

- 密钥按接口地址保存在 macOS 系统钥匙串，不写入游戏库、普通设置或日志；切换地址不沿用另一个地址的密钥。
- 仅在明确确认后调用；指定页面会发送必要正文与来源地址，按名称查找会发送你输入的名称和补充线索。搜索及模型调用均可能收费。
- 不自动上传游戏本体、存档、私人目录或整份游戏库。公开页面也会向页面所属网站发起请求；不读取本机、内网或文件地址。
- 批量 DLsite 补全不自动调用付费 AI；已有外部资料会被跳过，需逐部预览确认。
- AI 即便附有真实引文也可能理解错误，引用是核对线索，不是事实保证。重要信息仍需人工核对。

## 局域网与本地模型

模型和搜索接口各有独立的 **“授权当前局域网接口”** 开关。填好完整 HTTP 地址后，打开并确认风险提示，才允许连接该地址；更换地址、端口或路径后自动撤销，切换搜索方式也撤销搜索授权。模型授权不等于搜索授权，撤销会取消当前资料任务。支持私有 IPv4、IPv6 ULA 和本地服务名；不允许用此开关授权公网明文 HTTP。

HTTP 不加密，正文和密钥可能被网络上的其他设备读取，只在可信网络使用，更推荐 HTTPS 或加密隧道。应用不自动开放端口、不修改防火墙或服务监听配置。**网页正文及图片仍只允许公开 HTTPS**，不因接口授权而读取内网页面。

如果模型在另一台电脑，不能将 Mac 的 `127.0.0.1` 当作那台电脑。服务若只监听本机，单纯换成局域网 IP 仍连不上；可自行将服务安全地配置为局域网监听，或使用加密隧道。地址应包含 `/v1/chat/completions` 等实际路径，模型名称按服务的模型列表填写，不从显示名称猜测。

在 **“本地模型与兼容选项”** 中可调整：

- 模型等待上限：九十秒、三分钟、五分钟或十分钟，默认三分钟。
- 单次正文长度：八千至四万五千字，默认一万六千字；超出部分截断，未覆盖的字段可能缺失，不自动分段增加调用。
- JSON 对象输出：仅服务支持时启用，默认关闭；不支持会提示失败，不会默默降级重试。
- 关闭兼容模型的思考模式：仅聊天协议发送 `chat_template_kwargs.enable_thinking=false`，默认关闭，需服务支持。

模型单独返回的思考字段不作为资料读取；正文开头完整的 `<think>…</think>` 可剥离。只有思考、未闭合思考或无法解析的答案不会保存。类型需有明确类型词的原文引文，不能仅凭玩法描述猜出分类；其他字段仍可能理解错误，需核对预览。

## 保存与刷新

外部资料单独记录来源，不伪造 RJ，也不冒充 DLsite 作品；与旧版 DLsite 元数据兼容。资料、来源引文及手改标记保存在游戏库旁挂文件，分类和未知扩展字段保留。

刷新同一来源保留手改字段；未勾选字段保留该作品已有值，不会因缺失而清空。更换来源会在预览提示，不混入旧作品资料。手工修改过的字段不再以原 AI 引文背书；资料来源仍保留以便核对。

原游戏名称、文件和存档不变。自动分类根据已确认的作品类型更新，人工分类调整保留。外部来源 URL 作为资料身份；换用不同地址时会按更换来源处理，请核对提示。
